# Be My Valentine 💕

An interactive Valentine's Day invitation web app built with React and TypeScript. Features a playful "No" button that moves away when hovered, smooth animations, and a celebratory confetti effect when "Yes" is clicked.


## Live Demo 🌐

Check it out: [https://hiiiiiiiadammm.netlify.app/](https://hiiiiiiiadammm.netlify.app/)


## Tech Stack 🛠️

- **Frontend**: React 19 with TypeScript
- **Build Tool**: Vite
- **Animations**: Framer Motion
- **Styling**: Tailwind CSS
- **Icons**: Lucide React

## Features ✨

- Interactive invitation with a mischievous "No" button that teleports on hover
- Beautiful animations and transitions between screens
- Floating hearts background animation
- Confetti celebration effect on success
- Responsive design for mobile and desktop
- Customizable images and messages

## Getting Started 🚀

### Prerequisites
- Node.js (version 16+)

### Installation
1. Clone the repository
2. Install dependencies: `npm install`
3. Run locally: `npm run dev`

The app will be available at `http://localhost:5173`
